# Figma Local Bridge

[English README](README.md) · [Правила для агента](AGENTS.md) · [Безопасность](SECURITY.md)

Неофициальный локальный MCP-сервер и development-плагин Figma. Читает и редактирует открытый Design-файл: создаёт настоящие фреймы, текст, автолейаут, компоненты и переходы. Этот проект не требует Figma API token или OpenAI API key; авторизация и лимиты твоего AI-клиента и права доступа Figma сохраняются.

## Быстрый запуск

Нужны Node.js 22+, npm, Figma Desktop, редактируемый файл и MCP-клиент с локальным stdio. Сервер и Figma должны работать **на одном компьютере**. Удалённый контейнер или обычный веб-чат не подключаются к нему как к облачному MCP.

1. Скачай **исходники** репозитория, открой терминал в папке и выполни:

   ```sh
   npm ci
   npm run check
   npm run build
   ```

2. Для Codex добавь сервер, заменив путь на свой абсолютный:

   ```sh
   codex mcp add figma_local_bridge -- node "/полный/путь/figma-local-bridge/server.mjs"
   codex mcp list
   ```

   Для других локальных MCP-клиентов: stdio, команда `node`, аргумент — абсолютный путь к `server.mjs`. Готовые TOML/JSON-примеры и вариант для Windows есть в [основном README](README.md#2-connect-your-mcp-client). Если клиент не находит Node, укажи полный путь к исполняемому файлу. Перезапусти MCP-подключение после настройки.

3. В Figma Desktop открой файл → **Plugins → Development → Import plugin from manifest…** → выбери `dist/manifest.json`, путь к которому напечатала сборка.

4. Запусти **Figma Local Bridge** и оставь окно открытым. Запусти MCP-клиент или `npm run status` — появится **Connected to local bridge**. `connected: false` в статусе значит, что локальный сервер уже работает, но плагин ещё не подключён.

Если Figma просит plugin ID: создай development-плагин через **Create new plugin**, возьми выданный `id`, добавь строковое поле `pluginId` в `.local/settings.json`, сохранив `port` и `token`, и повтори `npm run build`. Не копируй чужой ID и не редактируй только сгенерированный manifest: следующая сборка его перезапишет.

## Что сказать агенту

> Прочитай `/полный/путь/figma-local-bridge/AGENTS.md`. Используй MCP `figma_local_bridge`. Сначала проверь статус и прочитай документ, сообщи название подключённого файла. Пока ничего не меняй.

Если агент работает из другой папки, явно передай ему `AGENTS.md`: он не обязан автоматически находить инструкции соседнего проекта. В файле есть правила выбора документа, шрифтов и координат, структура JSON-команд, проверка результата, работа с тайм-аутами и ограничения удаления.

## Примеры и диагностика

```sh
npm run status
node cli.mjs document
node cli.mjs fonts
```

Для тестовой карточки возьми `examples/card.json`, замени `REPLACE_WITH_DOCUMENT_ID` на текущий `documentId`, проверь свободные координаты и выполни `node cli.mjs create_nodes examples/card.json`. Для PNG укажи возвращённый ID узла и актуальный `targetDocumentId` в `examples/export.json`, затем выполни `node cli.mjs export_node examples/export.json preview.png`.

Один подключённый файл за раз. Для смены файла закрой старый плагин и запусти его в новом; перечитай документ. `documentId` меняется при запуске плагина и не является постоянным Figma file key.

Чтение документа возвращает смешанные `fontName` и `fontSize` как JSON-строку `"mixed"`. Точные ссылки на прочитанные узлы, включая вложенные слои экземпляров, сохраняются до завершения текущего запуска плагина. После перезапуска заново прочитай соответствующего родителя, прежде чем использовать ID его дочерних узлов.

- Порт по умолчанию — `127.0.0.1:3848`; bridge не слушает локальную сеть.
- Сервер автоматически запускается в фоне при новом MCP-подключении или вызове `npm run status`. `npm run stop` останавливает только эту копию после завершения команды. Уже открытое MCP-подключение само не поднимает остановленный bridge: переподключи MCP-клиент или выполни `npm run status`. Чтобы сервер оставался выключенным, отключи его запись в клиенте.
- Если порт занят, не останавливай чужой процесс: останови свой bridge, измени `port` в `.local/settings.json`, пересобери и перезапусти клиент/плагин.
- При ошибке pairing пересобери плагин из той же папки, из которой запущен сервер, и открой его заново.
- При тайм-ауте или частичной ошибке сначала проверь макет: команда могла уже примениться. Не повторяй запись вслепую.
- Ошибка команды показывается отдельно от состояния соединения с мостом и содержит точную причину. Ошибка чтения не означает обрыв связи. После ошибки записи проверь макет перед повтором: изменения могли примениться частично.
- При `Unable to establish connection to Figma after 10 seconds` проверь `figma_status`: ошибка операции Figma может возникнуть при живом локальном соединении. Для вложенного узла сначала прочитай известного родителя и используй точный ID дочернего узла в той же сессии плагина.
- Ошибки запуска сохраняются в приватном `.local/bridge.log`. Перед отправкой логов убери сведения о файле и сессии.

Полный список 10 инструментов, свойства узлов и ограничения — в [README](README.md#tools). Нет произвольного JavaScript, переменных, variant sets и публикации библиотек. Макет использует шрифты, доступные в Figma; агент должен сначала проверить их.

## Как делиться

Отправляй ссылку на репозиторий или архив **исходников**, не всю рабочую папку. `.local/settings.json` и `dist/ui.html` содержат локальный токен. Не публикуй `.local/`, `dist/`, `.env`, логи, экспорты чужих макетов и `node_modules/`. Каждый пользователь делает `npm ci` и `npm run build` у себя — получает свой токен.

Проверки: `npm run check`, `npm run build`, `npm test`. Автотесты используют настоящий MCP SDK и имитацию плагина, а не живой макет. CI для Linux/macOS/Windows запустится после публикации репозитория; настройка CI не означает, что эти платформы уже проверены вручную.
